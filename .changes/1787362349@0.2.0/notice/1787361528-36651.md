# Release v0.2.0

This release keeps the HTTP client/server integration in the SDK workspace as the `fact-http` package, so SDK, conformance, and CLI consumers can build against one coordinated crate set while preserving the Axum server and blocking HTTP client affordances.

- Restored the Axum HTTP binding and reqwest client support as the in-tree `crates/fact-http` package.
- Updated SDK conformance tests and CLI consumers to depend on the workspace `fact-http` crate instead of a sibling repository checkout.
- Removed SDK CI's clone of the sibling HTTP repository; the SDK workspace now carries the HTTP crate needed for lint, test, and release checks.
- Added support for authenticated remote ledger clones by storing optional bearer tokens with named remote configuration.
- Expanded release automation with dedicated tag and release phases and deploy helpers.
- Refreshed dependency locking for the updated workspace and CI toolchain.
