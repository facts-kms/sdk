# Initial Release

Facts Protocol v0 now has a portable Rust/SQLite reference implementation for
signed protocol objects, rebuildable projected state, local CLI workflows, HTTP
integration, and conformance validation.

- Implements canonical JSON, Markdown, CBOR, Ed25519/COSE signing, Merkle
  commitments, snapshots, bundles, and proof formats.
- Provides SQLite storage, migrations, WAL recovery, backup/restore,
  deterministic lexical search, and rebuildable projected read models.
- Supports proposition, deliberation, decision, settlement, lifecycle,
  authorization, synchronization, directory, and reconciliation workflows
  through the SDK and `fact` CLI.
- Includes an Axum HTTP binding for discovery, fetch, push, pull, query, proof,
  and structured error handling.
- Ships an executable conformance corpus for the registered Facts Protocol v0
  object schemas and authority rules.
